# 📇 Contact Manager

A simple contact management application built with Python.

The project provides basic functionality for managing contacts, including adding, editing, deleting, and searching for contacts.

## ✨ Features

- ➕ Add new contacts
- ✏️ Edit existing contacts
- 🗑️ Delete contacts
- 🔍 Search contacts
- 📋 Display contact information

## 🛠️ Technologies

- Python

## 🎯 Purpose

This project was built as a practical exercise to improve Python programming skills and understand how to structure a small application using Object-Oriented Programming.
